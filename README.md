# pf2e-foundry-exploration-automation
A set of macros that may boost an experience of exploration activity processes in Foundry's Pathfinder 2e System.

## How To
Steps below to install and use this module in your Foundry Server.

* check out the repo to your modules folder
* enable the module it in your game
* in your macros folder you may find all the necessary macros to use the module in a folder.
* when you select a Region you can:
   - trigger Main macros -- to get the main menu with options
   - trigger UnregisterMacros -- to unregister all the tokens from the region, so they can trigger logic a second time (may be useful if your tokens had already triggered checks in Region, but by a reason you want to have it again)
   - trigger all the Player tokens versus selected Region AS IF they have entered it. May be useful in a real case, when by a reason not all of them can actually enter a region, or if it had happened in a narrative, but not on the real map.
